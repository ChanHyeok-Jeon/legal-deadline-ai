# legal-deadline-ai · 법정기간 계산기 + AI 문서 읽기

> 송달 문서를 넣으면 **AI가 사건 종류와 기준일을 읽고**, 계산은 **법 규정을 그대로 옮긴 규칙 엔진**이 합니다.
> 결과에는 계산 과정, 근거 조문, AI가 근거로 든 문장을 함께 보여 줍니다.

| | |
|---|---|
| **기간** | 2026.10 |
| **성격** | 개인 프로젝트 |
| **계기** | 로펌 송무 실무자와 이야기하며 "기한 계산"이 반복 업무라는 것을 듣고 시작 |
| **데모** | https://jeon-chanhyeok.cloud/deadline/ |

<br>

## 문제

불변기간(항소, 상고, 즉시항고 등)은 하루만 넘겨도 권리를 잃습니다. 계산 규칙 자체는 정해져 있지만 실무에서는
① 문서에서 사건 종류와 송달일을 찾아 옮기고, ② 초일 불산입·주/월 계산·토요일과 공휴일 연장을 적용하는 일을 매번 반복합니다.

이미 좋은 무료 계산기가 있어 ②는 해결돼 있습니다. 이 프로젝트는 **①을 AI로 줄이되, ②는 AI에 맡기지 않는 구조**를 실험했습니다.

## 구조

```
[입력]  자연어 질문 · 문서 붙여넣기 · 파일 첨부(HWP · HWPX · DOCX · PDF · 사진, 저장하지 않음)
    ↓
[글자 추출]  HWP 5.0 레코드 직접 파싱 · HWPX/DOCX XML · PDF 텍스트 레이어
             사진·스캔 PDF는 Claude Haiku 4.5(Bedrock)가 글자를 옮겨 적음
    ↓
[AI 읽기]  Amazon Bedrock (Nova Pro) · tool use로 절차·기준일·근거 문장만 구조화해서 반환
           질문의 '어제' 같은 표현은 어떤 날짜로 해석했는지 함께 반환
    ↓
[코드 검증]  근거 문장과 날짜가 실제 문서에 있는지 확인 → 없으면 경고
    ↓
[사람 확인]  절차·기준일을 화면에서 고칠 수 있음
    ↓
[규칙 엔진]  초일 불산입 → 일/주/월/년 계산 → 토요일·공휴일 연장 (민법 제157·159·160·161조)
             초일 산입·휴일 연장 안 함 토글 (형사 시효·구속기간 등, 형사소송법 제66조 단서)
    ↓
[결과]  만료일 · 계산 과정 · 근거 조문 · 경고
```

| 원칙 | 이유 |
|---|---|
| 계산은 AI가 하지 않는다 | LLM은 날짜 계산을 틀릴 수 있고, 불변기간은 하루 오차도 치명적 |
| AI의 근거를 코드로 다시 확인한다 | AI가 문서에 없는 날짜를 지어내면 경고, 질문에 분야가 없으면 AI가 고른 분야를 확인하게 함 |
| 모델을 역할별로 고른다 | 한국어 사진 글자 읽기는 Nova에서 환각이 나와 Claude Haiku로 분리 |
| 계산 과정을 전부 보여 준다 | 사람이 한 단계씩 검토할 수 있어야 실무에서 믿고 씀 |

## 지원 절차 (16개)

민사 항소·항소이유서·상고·상고이유서·즉시항고·지급명령 이의·답변서, 형사 항소·항소이유서·상고·상고이유서·즉시항고,
행정 취소소송·행정심판, 가사 항소, 상속포기·한정승인. 근거 조문은 [`deadline/rules.py`](deadline/rules.py)에 있습니다.

## 검증

```bash
pip install -r requirements.txt pytest
python -m pytest -q      # 23 passed
```

HWP·HWPX·DOCX 글자 추출과 잘못된 파일 거부도 테스트합니다 ([`tests/test_fileread.py`](tests/test_fileread.py)). 계산 테스트는 추석·노동절·제헌절·대체공휴일 연장, 2월 말일 처리(민법 제160조 제3항) 등 까다로운 경우를 손으로 계산한 값과 비교합니다 ([`tests/test_calc.py`](tests/test_calc.py)).

## 실행

```bash
pip install -r requirements.txt
uvicorn app:app --port 8007     # AI 읽기를 쓰려면 AWS 자격 증명(Bedrock) 필요
```

## 한계

- 현직 송무 담당자에게 절차·기간 검증을 받는 중입니다. 검증 결과에 따라 절차와 규칙을 고칠 수 있습니다.
- 공휴일 데이터는 2025~2027년만 반영했습니다 ([`deadline/data/holidays_kr.json`](deadline/data/holidays_kr.json)). 출처마다 다른 날짜는 "확인 필요"로 표시합니다.
- 전자송달 간주(등재 통지 후 1주)는 실무 확인을 거쳐 다음 버전에 넣을 예정입니다.
- 스캔한 이미지 PDF는 글자가 없어 읽을 수 없습니다(OCR 미지원).
- 시연용 문서는 모두 가상입니다. 실제 사건 문서와 개인정보는 넣지 마세요.

> 계산 결과는 참고용이며 법적 효력이 없습니다. 실제 기한은 사건 기록과 법원 공지로 확인하세요.
